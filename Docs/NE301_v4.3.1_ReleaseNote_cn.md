## 发布概览

v4.3.1 是自 v2.1.0 以来规模最大的一次发布：Flash 分区与内存布局重构、WiFi 主机栈整体迁移到 WiseConnect 4.1.1 SDK、全新抓拍上传管道、整合包一键升级，并伴随大量现场稳定性修复。

## 主要新功能

- **整机一键升级（OTA Bundle）**：`make pkg-bundle` 将全部固件打成一个包，Web 端一次上传完成整机升级。支持分区表变更的布局迁移、同版本条目勾选跳过、跨型号固件包硬拒绝、FSBL 载荷先校验后写入。
- **WiFi 子系统全面升级**：主机驱动迁移至 WiseConnect 4.1.1 SDK；新增 WiFi 固件 OTA 升级（版本不匹配自动引导）；WiFi 国家码设置（us / eu / jp / kr / cn）；AP 侧自建 DHCP 服务器（粘性租约）；SPI 总线与主机栈一系列加固。
- **抓拍上传管道**：四种上传模式（即时 / 批量 / 定时 / 仅本地）、MQTT 批量发布与 Webhook 投递、低功耗唤醒调度、SD 热插拔自动切换、Web 记录管理界面与 REST API。
- **HaLow (802.11ah) 完整支持**：mm6108 / mm8108 双芯片构建切换、射频参数与扩展国家码 Web 配置、省电模式 Web 开关（默认关闭）、与 PoE / 4G 的软件强制互斥。
- **Web 管理界面大改版**：Web 资源独立分区，损坏时自动进入内置 Web Recovery；新增文件管理（Flash / SD）；固件升级中心覆盖 APP / Web / 模型 / FSBL / WiFi / 整合包并带期望版本校验；连接与实时推流稳定性大修。
- **AI 与模型**：STEdgeAI 2.2 / 3.0 / 4.0 运行时编译期统一切换（本发版线为 4.x）；AI 分区扩至 8MB A/B 双槽；新增人体姿态估计、指针仪表读数、实例分割、BlazeFace 人脸检测。

## 重要修复

- Web 实时预览晚连黑屏：按客户端做关键帧同步，入流延迟至多一个 GOP。
- Web 连接与推流稳定性大修：单次请求连接、静态资源 etag/304 缓存、视频帧 FIFO 复制、WS 发送缓冲上限，消除手机链路 `err_network` 弹窗与花屏。
- 视频管道停止死锁：`video_pipeline_stop()` 改为 3 秒上限 + 强制回收，不再卡死 HTTP 任务。
- 启动决策定时器线程栈溢出 HardFault：决策移至独立大栈线程。
- JPEG 编码尾部截断：修复浏览器预览底部马赛克、整图渲染不全。
- XSPI 擦除忙等饿死看门狗：消除无声复位、无日志的现场复位问题。
- RTMP 推流：修复每帧末尾 NAL 截断（底行宏块错误）；推流现开机自动启动，不再空等外部调用（此前每次重启损失约 6 分钟录像）。
- 摄像头与编码器：修复缓冲竞争撕裂帧、编码器冷启动全 INTRA 锁死（现自动通过 QP 地板步进逃逸）。

## ⚠️ 升级必读

1. **必须按顺序升级**：Flash 分区表已重新设计，从 v2.1.0 升级必须遵循
   **SensorExt APP → Web Recovery → Web → FSBL → WiFi → 模型包 →（按需）HaLow APP**。
   **首步不得使用 HaLow 版 APP**；跳过或打乱顺序将导致 Web 界面无法访问。详见 [OTA 更新指南](./NE301_v4.3.1_OTA_Update_Guide_cn.md)。
2. **首次开机将重格式化内部 Flash**（LittleFS 分区已移动）：**MQTT TLS CA / 客户端证书 / 私钥文件会丢失**，已启用 MQTTS 的用户请在升级前备份并于升级后重新上传。配置、WiFi 凭据等 NVS 数据与全部 SD 卡数据均保留。
3. **配套版本要求**：WiFi 固件升级至 `2.16.5.108`、FSBL 升级至 `1.0.3.1`、模型包必须使用 4.x 前缀（与 APP 主版本对齐，否则触发版本校验告警）。
4. **固件包型号门禁**：OTA 包头记录设备型号，跨型号固件包（如 NE302 的包装到 NE301）会被设备拒绝；未标注型号的旧包放行。
5. 完成本版升级后，后续整机升级（含分区表变更场景）可直接使用**整合包一键升级**，无需再逐个固件手动处理。

## 已知问题

- WiFi 固件 OTA 升级的推送阶段需约 1–3 分钟，期间请勿断电。
- 整合包烧录不走 AB 槽位（强制直烧），烧录期间请勿关闭浏览器页面或断电。
