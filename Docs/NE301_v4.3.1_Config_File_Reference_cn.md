# NE301 设备配置文件字段说明（v4.3.1 / 配置模式 v2）

> 适用对象：网页「固件升级 → 导出」下载的设备配置 JSON（对应接口 `GET /api/v1/device/config/export` 与导入接口 `POST /api/v1/device/config/import`）。
> 字段含义、默认值与取值范围以固件代码为准（`Custom/Core/System/json_config_mgr.h` 结构体定义、`json_config_mgr.c` 默认值与归一化、各服务枚举）；网页设置入口以实际页面为准。

## 导入语义（先读这个）

- **合并不是重建**：导入只叠加文件里实际存在的键；文件里缺失（或被你删掉）的键**保持设备当前值**，不会回退出厂默认。
- **版本门**：`config_version` 大于固件当前版本（现为 2）的文件被整份拒绝；v1 旧文件正常导入，导入后版本标记钉回 2。
- **网络参数恒写入**：导入网络字段会立即写入 RAM+NVS，与设备是否已连接无关——不会因链路在连而跳过或拒绝写入；生效点=各消费方下次读取的时机（多为下次重启/下次连接，详见 `network_service` 一节的说明）。
- 各字段「导入」列标记：
  - ✅ 随导入生效
  - 📄 仅导出留档，**导入时忽略**（设备绑定信息或源设备运行快照）
  - 🔧 随导入生效，但先经归一化/钳位（见各表）
- 敏感字段说明：文件**明文**携带 WiFi 密码、MQTT 密码、RTSP 密码、RTMP 流密钥、Webhook 密钥、管理密码，注意保管。

## ⚠️ 当前固件未实际使用的字段

以下字段会正常**存储、导出、随导入往返**，但固件里**没有任何功能读取**它们——设置后不会改变设备行为（导入它们也无副作用）。多数是历史遗留或为后续版本预留；标注以 v4.3.1 代码 grep 核查为准：

| 字段 | 说明 |
|---|---|
| `device_service.image_config.brightness` / `contrast` | 亮度/对比度：无消费方（网页本版也未开放调节） |
| `device_service.image_config.aec` | 自动曝光开关：无消费方 |
| `device_service.image_config.capture_disable_comm` | 仅在设备服务内拷贝/记日志，抓拍上传路径未读取，未见生效 |
| `work_mode_config.work_mode` / `image_mode.enable` | 固件只有图像（抓拍）一种工作模式，两个字段无消费方 |
| `work_mode_config.video_stream_mode.enable` | 遗留的工作模式父级开关：推/拉流由 rtmp_enable / rtsp_enable 各自独立控制，此开关无消费方 |
| `work_mode_config.io_trigger[]` 整组（`pin_number`/`enable`/`input_enable`/`output_enable`/`input_trigger_type`/`output_trigger_type`） | IO 触发注册 API 存在但无调用方，网页序列化代码也已注释——未接线 |
| `capture_upload_config.max_pending_records` | 仅存储与网页展示，上传管线未读取该上限 |
| `network_service.poe.dhcp_retry_interval_ms` | PoE 驱动未读取 |
| `network_service.cellular.authentication` / `operator` | 蜂窝模组配置未使用这两个字段 |
| `auth_mgr.session_timeout_ms` / `enable_session_timeout` | 登录会话无超时控制逻辑，未消费 |

对照：同段里容易误以为没用的字段**实际在用**——`ai_debug` 全组（`ai_enabled`/`ai_1_active`/`confidence_threshold`/`nms_threshold`/`overlay_results`/`inference_interval_ms` 经 AI 服务下发到视频节点与模型后处理，`ai_1_active` 还决定唤醒抓拍的模型槽）、`light_config.light_threshold`（唤醒路径的光控判定）、`mqtt_service` 的缓冲/超时参数（`tx_buf_size`/`rx_buf_size`/`outbox_expired_timeout_ms` 等由 MQTT 客户端库消费）。

## 顶层包装

| 字段 | 类型 | 说明 |
|---|---|---|
| `export_version` | string | 导出格式版本，当前 `"1.0"` |

## config 元数据

| 字段 | 默认 | 说明 | 导入 |
|---|---|---|---|
| `config_version` | 2 | 配置模式版本。大于固件版本的文件被拒；导入后固件将其钉回 2 | 📄（门控用，不落盘为文件值） |

## device_info（设备信息）——整段仅导出

网页入口：设备信息页。**全部字段导入时忽略**：这些是设备绑定或运行派生值，导入他机文件不会覆盖本机身份。

| 字段 | 说明 |
|---|---|
| `device_name` | 设备名。默认按 MAC 生成 `NE301-XXXXXX`（后 3 字节）；出厂 MAC 烧录后跟随烧录值 |
| `mac_address` | 设备 MAC（烧录了出厂 MAC 时为烧录值，否则芯片报告值） |
| `serial_number` | 序列号（产线写入，默认 `SN202500001`） |
| `hardware_version` / `software_version` | 硬件/软件版本（软件版本随固件自动更新，导入无效） |
| `camera_module` / `extension_modules` | 摄像头模块 / 扩展模块描述 |
| `storage_card_info` / `storage_usage_percent` | 存储卡状态与占用（运行时快照） |
| `power_supply_type` / `battery_percent` | 供电类型与电量（运行时快照） |
| `communication_type` | 当前实际活跃链路（运行时快照） |

### isp_config（自定义 ISP IQ 参数）

机器生成的参数段，完整映射 STM32 ISP 库的 IQ 结构。**仅在 `image_config.isp_mode=255` 且本段 `valid=true` 时生效**；由网页 ISP 自定义模式的导出/导入功能维护，**不建议手工编辑**。随配置文件导出/导入。字段清单（`valid` 为整段有效性标志）：

| 分组 | 字段 | 说明 / 范围 |
|---|---|---|
| 统计行剔除 | `stat_removal_enable`, `stat_removal_head_lines`(0–7), `stat_removal_valid_lines`(0–4094) | 剔除图像顶部无效统计行 |
| 去马赛克 | `demosaic_enable`, `demosaic_type`(Bayer 图案 0–4), `demosaic_peak`/`demosaic_line_v`/`demosaic_line_h`/`demosaic_edge`(均 0–7) | 插值参数 |
| 对比度 | `contrast_enable`, `contrast_lut[9]` | LUT（LUM_0–LUM_256，各 0–394） |
| 统计区域 | `stat_area_x/y/width/height` | AEC/AWB 统计窗口（像素） |
| 传感器手动增益/曝光 | `sensor_gain`(mdB), `sensor_exposure`(µs) | AEC 关闭时的静态值 |
| 坏点算法 | `bad_pixel_algo_enable`, `bad_pixel_algo_threshold` | 动态坏点检测 |
| 坏点静态强度 | `bad_pixel_enable`, `bad_pixel_strength`(0–7) | 静态坏点修补强度 |
| 黑电平 | `black_level_enable`, `black_level_r/g/b`(各 0–255) | 逐通道黑电平 |
| AEC | `aec_enable`, `aec_exposure_compensation`(−4~+4 EV), `aec_anti_flicker_freq`(0=关, 50, 60) | 自动曝光算法 |
| AWB（5 组档案） | `awb_enable`, `awb_label[5]`, `awb_ref_color_temp[5]`, `awb_gain_r/g/b[5]`, `awb_ccm[5][3][3]`, `awb_ref_rgb[5][3]` | 白平衡档案：标签/参考色温/增益/色彩矩阵/参考 RGB |
| ISP 手动增益 | `isp_gain_enable`, `isp_gain_r/g/b` | AWB 关闭时静态增益（100000000 = 1.0×） |
| 静态色彩转换 | `color_conv_enable`, `color_conv_matrix[3][3]` | 矩阵元素 100000000 = 1.0 |
| Gamma | `gamma_enable` | Gamma 使能 |
| 传感器延迟 | `sensor_delay` | 帧数 |
| Lux 标定 | `lux_hl_ref`/`lux_hl_expo1`/`lux_hl_lum1`/`lux_hl_expo2`/`lux_hl_lum2`（高亮参考）, `lux_ll_*`（低亮参考）, `lux_calib_factor` | 环境光估计标定 |
